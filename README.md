# Hotel Reservation Operations Analytics | Power BI

## Project Overview

An interactive Power BI project developed to analyze hotel reservation
operations and generate business-focused insights.

## Objectives

- Analyze booking demand
- Understand guest booking behaviour
- Evaluate stay performance
- Analyze staff and room performance
- Identify booking and stay problems
- Provide an executive summary

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Project Workflow

Data Collection → Data Cleaning → Data Modeling → KPI Development
→ DAX Measures → Dashboard Development → Business Insights

## Dashboards

1. Booking Demand Analysis
2. Guest Booking Behaviour
3. Stay Performance Analysis
4. Staff & Room Performance Analysis
5. Booking & Stay Issues Analysis
6. Executive Summary

## Key Skills Demonstrated

Power Query | DAX | Data Cleaning | Data Modeling |
KPI Analysis | Data Visualization | Business Intelligence
